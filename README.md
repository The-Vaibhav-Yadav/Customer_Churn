# Customer Churn Prediction Dataset

This repository contains the `Churn_Modelling.csv` dataset, which includes 10,000 records of bank customers. It is designed for predictive modeling and machine learning applications to determine customer retention and churn.

## Dataset Details
The file contains various features regarding the customer's interaction with the bank, including:
- **Demographics**: `Geography` (e.g., France, Spain, Germany), `Gender`, `Age`.
- **Financial Status**: `CreditScore`, `Balance`, `EstimatedSalary`.
- **Engagement**: `Tenure`, `NumOfProducts`, `HasCrCard`, and `IsActiveMember`.
- **Target Variable**: `Exited` (1 = Customer churned, 0 = Customer stayed).

### Usage
This data is ideal for Classification models (Logistic Regression, Random Forests, XGBoost, Neural Networks) to predict the likelihood of churning.
